# Perez-Serize NEC Predictive Tool

A clinical prediction engine for necrotizing enterocolitis built on 9 biomarkers. It scores both how abnormal each value is and how it is trending over time, and ships with an algorithm explainer and a validation dashboard (`nec_validation_dashboard.html`).

## Run it

Open <https://serize-dev.github.io/NEC-Tool/>, or download `index.html` and open it in a browser. It loads its libraries from a CDN, so it needs an internet connection.

**Demonstration software.** Not a medical device and not for clinical use. It does not replace clinical judgment.
